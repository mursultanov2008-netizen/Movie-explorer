# 🎬 Movie Explorer - Кинопоиск Lite

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![API](https://img.shields.io/badge/API-OMDb-green)
![License](https://img.shields.io/badge/license-MIT-orange)

**Movie Explorer** — это современное одностраничное приложение (SPA) для поиска фильмов, просмотра детальной информации и создания персональной коллекции избранного. Проект разработан в рамках учебного модуля "Библиотеки и Фреймворки в Веб-Разработке" и демонстрирует переход от ванильного JavaScript к компонентному подходу.

![Movie Explorer Preview](https://via.placeholder.com/800x400?text=Movie+Explorer+Preview)

## ✨ Возможности

### 🔍 Поиск и фильтрация
- **Умный поиск** с debounce-эффектом (задержка 500мс)
- **Расширенные фильтры**:
  - По году (диапазон)
  - По рейтингу (5+ до 9+)
  - По стране (США, Великобритания, Япония и др.)
  - По жанру (боевик, комедия, драма и др.)
  - По типу (фильмы, сериалы, эпизоды)
- **История поиска** — последние 10 запросов

### 🎯 Управление коллекциями
- **Избранное** ❤️ — сохраняйте понравившиеся фильмы
- **Watchlist** 📺 — список "К просмотру"
- **Персональные оценки** ⭐ — оценивайте фильмы по 5-балльной шкале
- **Комментарии** 💬 — оставляйте заметки к фильмам

### 📊 Продвинутые функции
- **Сравнение фильмов** ⚖️ — до 3 фильмов в сравнительной таблице
- **Рекомендации** 🤖 — подборки на основе жанра просматриваемого фильма
- **Режимы отображения**:
  - 📱 Сетка (grid) — для наглядного просмотра
  - 📋 Список (list) — с подробным описанием
- **Сортировка** по году, рейтингу, названию
- **Адаптивная верстка** для всех устройств

### 🎨 Интерфейс
- **Цветовая индикация рейтинга**:
  - 🟢 8+ — отлично (зеленый)
  - 🟡 7+ — хорошо (желто-зеленый)
  - 🟠 6+ — средне (оранжевый)
  - 🔴 <5 — низкий (красный)
- **Скелетоны загрузки** для плавного появления контента
- **Бесконечный скролл** для подгрузки результатов
- **Модальные окна** с детальной информацией

## 🛠 Технологический стек

### Frontend
- **HTML5** — семантическая верстка
- **CSS3**:
  - Flexbox и Grid для построения интерфейсов
  - Адаптивная верстка (mobile-first)
  - CSS-переменные для тем
  - Анимации и переходы
- **JavaScript (ES6+)**:
  - Асинхронные запросы (Fetch API)
  - Работа с LocalStorage
  - Debounce для оптимизации поиска
  - Модульная архитектура

### API и данные
- **[OMDb API](http://www.omdbapi.com/)** — база данных фильмов (ключ: `5ed3ebac`)
- **LocalStorage** — хранение пользовательских данных:
  - Избранное
  - Watchlist
  - Оценки пользователей
  - Комментарии
  - История поиска

### Инструменты разработки
- Живой сервер для разработки
- Git для контроля версий
